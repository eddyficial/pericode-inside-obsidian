# Contributing to PeriCode

This repository contains Obsidian release artifacts and user documentation.
Report reproducible bugs here with the plugin version, Obsidian version,
operating system and steps to reproduce. Never include credentials, private
notes, chat logs or screenshots containing personal information.

Submit code changes to the [source repository](https://github.com/eddyficial/pericode).
Follow its [contributor guide](https://github.com/eddyficial/pericode/blob/release/open-source/CONTRIBUTING.md)
for building and testing. Avoid editing the generated main.js directly.

Keep fixes focused and include verification for affected behavior. Preserve
permission checks, cancellation and secret protection. All contributions are
under the MIT license. Report suspected security vulnerabilities privately;
see the [security policy](https://github.com/eddyficial/pericode/blob/release/open-source/SECURITY.md).
